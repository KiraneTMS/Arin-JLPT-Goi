日本語 Word Play — JLPT Vocabulary Quiz

A beautiful, modern web quiz for Japanese vocabulary (JLPT N5–N1).

Features

3 Game Modes





Time Attack ⏱
Start with 20 seconds.





Correct answer streak of 3 → +3 seconds (max ~45s)



Wrong answer → −5 seconds
Survive as long as you can!



Normal 📝
Answer exactly 50 questions.
See your final score, accuracy, and best streak at the end.



Survival 🔥
Keep answering until you make 3 mistakes.
How many can you get right before it's game over?

Levels





N5 Beginner (~662 words)



N4 Elementary (~632 words)



N3 Intermediate (~1,784 words)



N2 Advanced (~1,793 words)



N1 Expert (~3,463 words)

Design





Dark sakura-inspired theme with falling petals



Smooth animations & modern UI



Fully responsive (mobile + desktop)



Multiple-choice questions with instant feedback

How to run

Just open index.html in a browser, or serve the folder:

cd nihon-quiz
python3 -m http.server 8080
# then open http://localhost:8080

(Using a local server is recommended because the app loads JSON vocabulary files via fetch.)
